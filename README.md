# 📊 Sales & Profit Analytics Dashboard  
A Python-powered analytics dashboard that processes sales data, generates business insights, and visualizes trends using Pandas and Matplotlib. Designed as a real-world data analyst portfolio project with clean structure, meaningful metrics, and interactive charts.

## ⭐ Overview  
This dashboard loads a CSV dataset and provides:  
- Summary business metrics  
- Monthly sales trend analysis  
- Category performance breakdown  
- Top product insights  
- Customer segment distribution  
- Profit forecasting  
- Interactive CLI dashboard  
- Multiple charts and visualizations  

Built with Python, Pandas, and Matplotlib for a professional, analyst-focused workflow.

## 🗂️ Project Structure
sales_dashboard/

### 2. Install dependencies

### 3. Run the dashboard  
python dashboard.py
